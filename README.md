Utility and Evaluation Function:

The code uses the function checkUtility() which calls a series of other functions to calculate the occurances
of various states of the game. These tracked heuristics are:
Number of Mills
Number of Closed Mills
Number of Blocked in Pieces
Number of Pieces Left
Number of Pieces that are 1 or 2 Pieces away from forming a mill
Number of Double Mills
Whether the state is a game win

These are then multiplied by various values in checkUtility() in relation to how beneficial
that state is to the player. This function is used for both utility and evaluation. 

Time Optimization:

Discussion on Chosen Functions:
The used evaluation function was decided on by testing which heuristics were most vital in leading to a winning state.
These were also weighed differently depending on the phase of the game. For example in phase 2 mills are valued higher than in phase 1 when you are
just initially placing pieces. The tracked heuristics as listed above were decided upon as they all contribute to a beneficial state for the player (the bot).
The choice of prioritizing things in beneficial states rather than negative states was made as otherwise more average states end up evaluated higher compared to ones.
Generally the game has a very good advantage state and therefore prioritizing positive states is better.
